# Changesets

Hello and welcome! This folder has been automatically generated by
`@changesets/cli`, a build tool that works with multi-package
repos, or single-package repos to help you version and publish your code.
You can find the full documentation for it [in our repository](https://github.com/changesets/changesets)

We have a quick list of common questions to get you started engaging with this
tool.

## How do I use git with changesets?

Please read the [detailed explanation](https://github.com/changesets/changesets/blob/main/docs/detailed-explanation.md).

## How do I add a changeset?

Run `pnpm changeset` from the repo root and follow the prompts. Every
platform package (apps, packages, tools) is locked to the same version —
adding a changeset for any of them bumps that shared version, whether or not
you're touching an npm-published package. `examples/i18next-demo` is
excluded since it's a demo app, not part of the shipped platform.

Commit the generated `.changeset/*.md` file alongside your change. When
enough changesets have accumulated, running the "Release" GitHub Action
bundles them into one version bump, commits it, and tags the release — that
tag is what triggers the actual npm and Docker publishes.
